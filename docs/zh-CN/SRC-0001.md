## 模块职责与实体

这是客户端与智能体交换数据的基础层。`Submission` 携带 `Op` 进入提交队列；`Event` 用相同请求 ID 关联 `EventMsg`。`UserTurn` 保存完整轮次配置，`TurnItem` 表示流中的消息、推理、工具和压缩项；`ResponseItem`/`ResponseInputItem` 则面向模型接口。权限、会话来源、语音、图片、上下文快照和跨智能体通信也在这一层定义。

## 主要规则

- `SRC-0001/rule/context-window-baseline-tokens`：剩余用户窗口的估计先扣除 **12,000 tokens** 基线；窗口不大于基线时返回 0，不做负数除法。
- `SRC-0001/rule/prefix-list-rendering-limits`：展示给模型的允许前缀最多 **100 项、5,000 字节**；按段数、总长度、字典序排序。超限添加截断标记。这是展示预算，不意味着底层权限规则失效。
- 默认只读与 workspace-write 策略都不开放网络；可写根必须可读，`.git`、`.agents`、`.codex` 等路径还有独立保护。`RequireEscalated` 与仍在沙箱中追加权限的 `WithAdditionalPermissions` 不同。
- `ReviewDecision` 默认拒绝，`AskForApproval` 默认 `OnRequest`。细粒度审批各开关独立控制提示；缺失的技能审批和权限申请开关默认为 false。

## 执行流程与兼容性

`SRC-0001/uc.sub/convert-turn-item-to-legacy-events` 把新式轮次项转换为旧事件：消息、推理、搜索等分别映射；`HookPrompt` 和 `Plan` 不生成旧事件，原始推理内容受独立开关控制。传输名称并不总等于 Rust 名称，例如 `TurnStarted` 仍输出 `task_started`，同时接受新别名。

工具结果可传纯文本或内容数组；内部 `success` 不进入 wire。MCP 图片保留已有 data URL，否则构造带 MIME 的 base64 URL；转换为纯文本时忽略图片和空白项。用户远程图片与本地图片共用序号，本地图片读取失败或格式不支持时写入说明占位符。技能/提及内容留给后续注入，不在基础输入转换中展开。

## 边界与追溯

`SRC-0001/rule/turn-context-item-persist-timing` 要求真实用户轮次记录上下文快照，轮中压缩恢复完整上下文后再次记录，供 resume/fork 重放。空 hook ID 被过滤，未知消息 phase 不能直接视作 final；`ThreadRollbackFailed` 和 `ActiveTurnNotSteerable` 不自动将轮次标为失败。`ThreadId` 使用非空 UUID v7，非法 UUID 解析失败。会话来源、产品限制、实时语音名称及序列化别名的完整枚举应查原始结构文件，不应靠界面文案推断。
