## 模块职责与实体

`AgentPath` 给智能体树提供规范名称；`ModelInfo`、`ModelMessages`、`ModelPreset` 描述模型能力、指令模板与选择器选项；`CollaborationMode` 和其 mask 负责局部配置更新。套餐、认证配置、网页搜索设置与 `CodexErr` 则连接服务能力、用户界面和失败处理。

## 主要规则

- `SRC-0003/rule/agent-name-charset`：名字仅限小写 ASCII、数字和下划线，不能空、含斜杠或使用保留段；绝对路径始于 `/root`，不能带尾斜杠。
- `SRC-0003/rule/auto-compact-token-limit-clamp`：压缩阈值为配置值与上下文窗口 **90%** 的较小值；缺少窗口时仅用配置值。模型有效窗口百分比默认 **95%**，与压缩阈值不是同一参数。
- 认证命令默认超时 **5,000 ms**，主动刷新间隔 **300,000 ms**；刷新间隔 0 表示禁用主动刷新，并非认证超时可设 0。
- UI 错误展示预算 **2,048 字节**，意外响应体展示最多 **1,000 字节**，截断需保留字符边界。

## 主要流程

`SRC-0003/uc.sub/build-model-instructions` 用 personality 值替换 `{{ personality }}`；模板缺失时回退 `base_instructions`。`Personality::None` 刻意替换为空串。完整 personality 支持要求模板占位符和三种变量均存在。

模型元数据转为 preset 后，根据认证模式筛选 API 可用模型，再将首个可见项设为默认；没有可见项时使用首项，空列表不会凭空产生默认。推理 effort 按 None 到 XHigh 的等级找最接近支持值。`CollaborationModeMask` 中 None 表示不改，Some(None) 表示清空，Some(Some(value)) 才是赋值。网页搜索覆盖配置逐字段合并，不能把空缺误当删除。

`SRC-0003/uc.sub/classify-codex-error` 先判断错误类别，再映射协议错误和 UI 文案。网络流、超时、连接等有可重试集合；额度不足、上下文超限、终止、沙箱拒绝不能由通用 retry 分类直接重试。沙箱拒绝优先显示聚合输出，再用 stderr/stdout，最后给退出码。

## 边界与追溯

未知套餐保留原始字符串，已知套餐识别不区分大小写；额度文案按套餐、专用限额名称和本地重置时间选择，**这里不是新的促销或额度承诺**。系统 locale 不可用时数字格式回退 en-US，负 token 计数显示为 0。`SRC-0003/rule/unexpected-response-cloudflare-friendly` 只在 403 且响应同时含 Cloudflare、blocked 时用专门文案。默认沙箱 ReadOnly、默认审查者 User 都是此快照的配置默认值，不代表所有部署的实际设置。
