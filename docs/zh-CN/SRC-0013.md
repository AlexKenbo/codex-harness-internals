# SRC-0013：工具定义、配置与注册计划

> 本文是三个 JSON 视角的中文导读，不是逐字段译本；标识符、参数与规则以当前仓库快照为准。

## 职责与关键实体

本模块回答“模型这一轮能看到什么工具，以及它们以什么 schema 暴露”。`ToolSpec` 覆盖 Function、Namespace、ToolSearch、LocalShell、ImageGeneration、WebSearch、Freeform；`ToolDefinition` 统一动态工具与 MCP 工具；`ToolsConfig` 将模型能力、环境、功能开关转成配置，`ToolRegistryPlan` 分别收集公开规格和处理器绑定。它也定义 shell、补丁、REPL、协作、CSV 任务、权限请求、用户输入、计划、图片、资源检索等工具接口。

实体入口：[结构](../../SRC-0013/structural.json)，精确 ID：`SRC-0013/entity/tool-spec`、`SRC-0013/entity/tools-config`、`SRC-0013/entity/tool-registry-plan`。

## 主要规则与数值

- `tool_search` 默认返回 8 个工具；CSV worker 默认并发 16、单项运行上限 1 800 秒，`max_workers=1` 表示顺序运行。
- `request_user_input` 建议 1 个问题、最多 3 个，每题必须有非空选项；标题不超过 12 个字符，选项标签为 1–5 个词。规范化强制 `is_other=true`，由客户端添加自由输入项。
- schema 清理把 `const` 改为单元素 `enum`，为 object 补 `properties`、为 array 补 `items`；顶层单独的 `null` 类型被拒绝。MCP 工具必须带 namespace，按显示名及组内工具名排序。
- Code Mode 的嵌套配置关闭自身两个开关，避免递归注册；工具定义按名称排序去重。`tool_suggest` 不进行 Code Mode 描述增强，且需要 ToolSuggest、Apps、Plugins 同时开启。
- WebSearch 的 Cached/Live 分别对应关闭/开启外部网络访问；Disabled 不创建工具。原图 detail 仅在模型支持时暴露。工具描述中的授权约束是该快照的接口约定，不代表当前会话自动获得权限。

核对：[规则](../../SRC-0013/rules.json)中的 `SRC-0013/rule/tool-search-default-limit`、`SRC-0013/rule/json-schema-singleton-null-prohibited`、`SRC-0013/rule/code-mode-nested-tools-config`。

## 用例流程

`SRC-0013/uc.sub/build-tool-registry-plan` 先读取配置；若启用 Code Mode，先构建隔离的嵌套计划，再注册 exec/wait；按环境选 shell，添加资源、计划、输入、权限、搜索、补丁、图片等工具，再按协作版本添加 v1/v2 工具，最后合并 MCP 命名空间和动态工具。安装建议先过滤客户端能力，再发确认请求，随后核对连接器 ID 与可访问状态，不能把“用户点击同意”直接视为安装完成。详见[用例](../../SRC-0013/use-case.json)。

## 边界与失败处理

没有环境时不注册依赖本地执行的工具；缺 namespace 或 schema 转换失败的 MCP 工具会记录错误并跳过，空命名空间也跳过。TUI 排除暂不支持安装的插件；缺失可发现工具时不添加安装建议工具。空问题选项被拒绝，不支持的 `Original` 图片 detail 清为 `None`。可从 `SRC-0013/uc.sub/sanitize-json-schema`、`SRC-0013/uc.sub/normalize-request-user-input-args` 追踪具体分支。

## 阅读提示

阅读时还需区分“工具已注册”“模型可见”“当前模式允许调用”三件事：处理器存在不保证提示词里展示，规格公开也不保证运行时门槛已满足。协作工具会按版本切换字段和结果形状；图片生成、搜索、REPL、安装建议分别受不同开关控制，不能只检查一个全局启用标志。
