# SRC-0009：会话启动、轮次循环与线程生命周期

> 本页是中文导读，不是 JSON 的逐字段译本。规则、结构和完整分支请以本模块原始数据为准。

原始数据：[规则](../../SRC-0009/rules.json) · [结构](../../SRC-0009/structural.json) · [用例](../../SRC-0009/use-case.json)

## 职责与关键实体

本模块串起 Codex 的主运行路径：线程启动、操作提交、模型轮次、委托子线程、审核与权限应答、历史派生、配置更新、身份注册和关闭。`Codex` 暴露 submission/event 队列及状态，`Session` 持有会话服务与历史，线程管理器负责线程集合，轮次上下文承载该轮配置。它是连接工具、上下文和模型客户端的总控层。

结构入口：`SRC-0009/entity/codex`。整体入口：`SRC-0009/uc.user/start-new-codex-thread`、`SRC-0009/uc.sub/spawn-codex-session`。

## 主要规则

- submission 通道容量 **512**，满时产生背压，关闭后提交返回 `InternalAgentDied`。启动后的首个事件必须是 `SessionConfigured`，事件 ID 为初始空字符串。
- `base_instructions` 优先级为配置覆盖、历史中保存的指令、模型默认指令。子智能体模型列表采用离线刷新策略；Guardian 审核器不继承调用方 exec policy，而使用内置安全检查。
- steer 需要非空输入、活动的 Regular 轮次，以及匹配的可选预期轮次 ID。回滚要求轮数至少 **1**、无活动轮次且存在持久化 rollout。
- 轮次前达到压缩阈值会压缩；轮次中还需 `needs_follow_up` 为真。切换到更小窗口时可用前一模型上下文先压缩。委托关闭先 Interrupt、Shutdown，再最多排空事件 **500 ms**。

对应规则：`SRC-0009/rule/submission-channel-capacity`、`SRC-0009/rule/base-instructions-priority`、`SRC-0009/rule/guardian-reviewer-bypass-exec-policy`、`SRC-0009/rule/steer-input-preconditions`、`SRC-0009/rule/thread-rollback-preconditions`。

## 典型流程

`run-model-turn` 先处理预压缩和上下文差异，再解析技能与插件、依赖及 hooks，记录用户输入，准备幽灵快照。循环收取待处理输入和邮箱消息，构造模型请求、处理采样结果；需要继续时执行工具后续或压缩，否则运行 Stop 与 AfterAgent hooks。Stop hook 只有提供有效续写提示时才能阻止结束。

委托线程把审批转交父会话或 Guardian，再将结果作为操作发回子线程。身份注册仅在功能启用且为有效 ChatGPT 身份时执行，校验 workspace、用户绑定和密钥材料，能复用缓存则不重新注册；API key 身份跳过。关闭会话取消任务、终止进程、刷新关闭 rollout，最后发出 `ShutdownComplete`。

用例：`SRC-0009/uc.user/run-model-turn`、`SRC-0009/uc.user/approval-request-through-delegate`、`SRC-0009/uc.user/register-agent-identity`、`SRC-0009/uc.user/shutdown-codex-session`。

## 边界与失败处理

等待审批被取消时返回 Abort、空答案或本轮空权限，不能视为授权。无输入且无待处理任务直接结束；无效图片先尝试替换后重试，无法修复才报告错误。AfterAgent 的 FailedAbort 会中止完成，FailedContinue 只记录警告。带外询问计数仅在 0→1 和 1→0 时切换暂停状态，并检查溢出与错误递减。中途历史快照和回滚标记会影响派生边界，不能简单按原始用户消息数截取。

参见 `SRC-0009/rule/cancelled-approval-defaults`、`SRC-0009/rule/invalid-image-recovery`、`SRC-0009/rule/out-of-band-elicitation-counter-bounds`、`SRC-0009/rule/thread-rolledback-truncation`。
