# SRC-0010：模型客户端、流式传输与请求复用

> 本页是中文导读，不是 JSON 的逐字段译本。规则、结构和完整分支请以本模块原始数据为准。

原始数据：[规则](../../SRC-0010/rules.json) · [结构](../../SRC-0010/structural.json) · [用例](../../SRC-0010/use-case.json)

## 职责与关键实体

本模块负责模型 API 请求：Responses 的 HTTP/SSE 与 WebSocket 路径、连接预热、增量输入、鉴权恢复、远程压缩、记忆摘要及实时 WebRTC。`ModelClient` 属于整个会话；`ModelClientSession` 只属于一个轮次；`WebsocketSession` 保存连接、上次请求和响应；`ResponseStream` 将后台流映射成调用方消费的事件。

入口：`SRC-0010/entity/model-client`、`SRC-0010/entity/model-client-session`、`SRC-0010/entity/last-response`。

## 主要规则

- WebSocket 仅在提供方支持、会话未禁用且未设置 SSE fixture 时启用。请求 Zstd 压缩还要求功能开启、ChatGPT 身份和 OpenAI 提供方同时成立。
- Responses 流式请求固定 `stream=true`、`tool_choice='auto'`；Fast 服务层序列化为 `priority`。reasoning、verbosity 各自受模型能力约束，`store=true` 仅用于 Azure Responses 端点。
- `prompt_cache_key` 使用会话 ID；窗口 ID 为 `{conversation_id}:{window_generation}`，generation 更新必定清空连接缓存。
- 增量请求要求全部非 input 字段一致，新 input 延续“前次输入 + 服务端新增条目”，并有非空 `previous_response_id`。不满足时发送完整请求。
- 流映射通道容量 **1600**；首个 Completed 才发送 `LastResponse`。预热使用 `generate=false`，不会生成答案。

对应规则：`SRC-0010/rule/responses-websocket-enabled`、`SRC-0010/rule/incremental-request-same-properties`、`SRC-0010/rule/incremental-request-input-is-extension`、`SRC-0010/rule/mpsc-event-channel-buffer`。

## 典型流程

每轮创建新的客户端会话，可先预连接、预热，再选择 WebSocket 或 HTTP 流。建立连接时加入身份、子智能体、轮次元数据与 beta headers；收到输出条目后积累它们，在 Completed 时记录用量和响应 ID。会话对象释放时可将连接放回缓存，但轮次粘性路由 token 不得跨轮复用。

远程压缩调用 `/responses/compact`，记忆摘要调用 `/memories/trace_summarize`，空输入都直接返回空结果。实时调用返回 SDP 给客户端，将 call ID 和 sideband headers 留给控制连接。存在 freeform `apply_patch` 工具时，还会把已识别的 shell 输出从 JSON 改写为 Exit code、Wall time、Output 等文本段落。

用例：`SRC-0010/uc.user/stream-model-turn`、`SRC-0010/uc.sub/prepare-incremental-request`、`SRC-0010/uc.user/open-realtime-webrtc-call`、`SRC-0010/uc.sub/reformat-freeform-apply-patch-output`。

## 边界与失败处理

握手超时采用提供方配置，不是统一常量。HTTP **426** 触发整场会话回退到 HTTP 并清空 WebSocket 缓存。遇到 **401**，仅在鉴权恢复器还有步骤时尝试恢复；永久刷新失败与暂时失败分别映射为不同错误，不能无限循环。流中多次错误继续转发，但失败遥测只记第一次。`turn_state` 仅在当前轮次重试和追加请求中原样回传，不能复用整个 `ModelClientSession` 到下一轮。

参见 `SRC-0010/rule/fallback-on-upgrade-required`、`SRC-0010/rule/recovery-permanent-vs-transient`、`SRC-0010/rule/turn-state-sticky-routing-contract`。

请求头也有明确作用域：父线程 ID 只为 ThreadSpawn 子智能体发送，其他子智能体类型仅有相应来源标签。WebSocket v2 的 beta header 不用于 HTTP 路径，计时指标 header 仅在显式开启时加入。连接复用与轮次状态复用是两件不同的事，前者能节省握手成本，后者若跨轮发生则会违反服务端路由契约。
